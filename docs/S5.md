# S5 — event-OOF adapters

Few-shot residual on the **locked** min-max TSDiff score. Image analogue: Sehwag trains a small head on tail images; we train a residual \(a_\psi\) on **train-fold Anomalies** mixed with nominals. Held-out events stay the Coverage@τ query set.

Does **not** overwrite `results/shell_s4`. Does **not** retrain GenIAS. τ is the frozen S4 value (0.105). Code map of every other method: [REPO.md](REPO.md). Math: [STEERING_MATH.md](STEERING_MATH.md) §6.

## What was wrong with the old `results/shell_s5`

The directory on disk before this run was **not** comparable to S4: old U-Net (~726k), τ=0.45, and the phase retrained GenIAS every fold. Do not cite that summary next to the locked table. `anogen s5` now writes a new summary in the same folder.

## Adapter (audited)

File: `src/anogen/shell/adapters.py`.

```
ε_FS(x_t, t, c)  =  ε_θ(x_t, t, c)  +  a_ψ(x_t, t, c)
```

| Piece | Code | Check |
|---|---|---|
| Backbone frozen | `AdaptedDenoiser`: `requires_grad_(False)` + `no_grad` on `backbone` | OK. Residual only is trained. |
| Residual | `ResidualAdapter`: 4× Conv1d, time MLP, channel embed | **Not LoRA** (docstring said “low-rank”; that was wrong). Full small CNN. |
| Train loss | ε-MSE on mix `anom_frac=0.5` train-fold anomalies + matched nominals | OK. Same objective as S1, new weights only. |
| Scale | Adapter sees **min-max** windows (`scaler.transform`) | OK. Matches the score. |
| Classifier | `AnomalyClassifier` on **raw** windows; rares = extra negatives | OK. `guided_ddim` applies it to inverse-scaled \(\hat x_0\). |
| Gate | Guidance only if acc_anom≥0.6, acc_nom≥0.6, acc_rare≥0.5 | OK. Head that cannot reject rares is dropped. |
| OOF | One adapter + one classifier **per held-out fold** | OK. `s5.py` loop. Weights: `adapter_fold{k}.pt`. |

## Scores (2026-09-09 run)

Frozen τ=0.105 / φ / 1536 donors. Fold-wise `_score_gallery` then mean. Div on fold-0 gallery. EDI = S5-extended union (do not mix with the 9-method EDI).

| Recipe | Cov. anom | Gap | ARP anom | Occ. | Div | EDI† |
|---|---:|---:|---:|---:|---:|---:|
| adapter-only | 0.063 | −0.013 | 0.455 | — | 2.04 | 1.66 |
| adapter+cls (cls dropped) | 0.021 | −0.003 | 0.416 | 0.69 | 2.60 | 2.01 |
| S5 + time_recon combined | **0.000** | −0.002 | 0.352 | 0.77 | 4.71 | 2.36 |
| S5 + time_both combined | 0.001 | +0.001 | 0.336 | 0.78 | 4.37 | 2.31 |

Classifier gate: **never** used. Fold 1 collapsed (acc_anom=1, acc_nom=acc_rare=0). Folds 0/2 ~chance on rares (0.43–0.44). The gate did its job.

Adapter is 54,593 / 315,841 ≈ **17%** of the score (not “7%”). Combined-without-adapter still has Coverage@τ 0.023; adding \(a_\psi\) drives that to ~0.
